TimeStamp for QuPath

Install and set up

Package 0.2.0-preview.20261001.3
For QuPath 0.6.0

TimeStamp records your spoken observations together with your image actions in QuPath. You install it once. Setup takes one sitting; most of the time is an unattended download.

Before you start, check you have:

  • QuPath 0.6.0, already opened once so its first-time setup is complete.
  • A supported computer: Windows 10 or 11 (x64), a Mac (Apple Silicon or Intel), or Linux (x64 or ARM64). Windows on ARM is not supported.
  • Internet access for the first setup. It downloads about 3.6 GB of speech models plus recording tools.
  • A microphone (built-in or connected).
  • Permission to install software. On a hospital computer, ask IT first.
  • The file TimeStamp-Doctor-0.2.0-preview.20261001.3.zip.

Install

  1. Note your QuPath folder, then close QuPath

    In QuPath, open Preferences and find User directory. Write it down. Then quit QuPath completely. The installer will stop if QuPath is still open.

  2. Unzip the download

    Windows: right-click the ZIP and choose Extract All. Mac: double-click the ZIP. Then open the TimeStamp-Doctor-0.2.0-preview.20261001.3 folder. Do not run anything from inside the ZIP itself.

  3. Run the installer for your computer

    WindowsDouble-click Install TimeStamp on Windows.bat. A setup window opens.
    MacDouble-click Install TimeStamp.command. If macOS blocks it, Control-click the file, choose Open, then Open again.
    LinuxOpen a terminal in the folder and run:
    bash "Install TimeStamp on Linux.sh"
    It may ask for an administrator password.

    If your computer or organization blocks the installer, stop and ask IT to approve it. Do not turn off security software.

  4. Confirm the QuPath folder

    The installer shows a folder and asks you to confirm it. If it matches the User directory from step 1, press Enter. If not, paste your folder and press Enter.

  5. Wait for all four stages

    Keep the window open. Do not close it while it is working.

    [1/4]Checks the package is complete. [2/4]Prepares the private recording tools. [3/4]Downloads the speech models. This is the longest step. [4/4]Installs TimeStamp and tests the microphone for 5 seconds. Say a sentence when asked; the window then tells you whether the microphone works.
    Setup is finished when you see: “TimeStamp is ready for the doctor.”

    If a download is interrupted, run the same installer again. Files already downloaded are reused.

Make a short test recording

Do this once before your first real session. Use a slide and speech with no patient information.

  1. Open the recorder

    Open QuPath and allow microphone access if asked. Choose Extensions → TimeStamp Extension → Open Clinical Session Recorder.

  2. Check the microphone

    Choose ⚙ Settings, select your microphone and choose Test microphone. Speak and check that the signal indicator moves.

  3. Record a few sentences

    Choose Start Recording and wait until it says Recording. Speak a few sentences and zoom or move around the slide. Try Pause and then Resume.

  4. Finish and review

    Choose Finish & review. The final transcript is prepared from the whole recording; keep QuPath open until it is ready. Replay and correct any wrong words.

  5. Save with audio, then reopen

    Choose Save Session, pick a folder and a name without patient details, and tick Include audio recording. Then choose More → Open saved session… and open that folder to confirm it reopens.

If all five steps work, TimeStamp is ready to use.

If something goes wrong

What you seeWhat to do
The installer is blockedAsk IT to approve it. Do not change security settings yourself.
“Please close QuPath completely”Quit QuPath (check it is not still running), then run the installer again.
“This package supports Windows x64 only”This computer runs Windows on ARM, which is not supported. Contact the study coordinator.
Windows mentions a missing DLLAsk IT to install the Microsoft Visual C++ 2015–2022 x64 runtime, then run the installer again.
The download stopped or failedCheck the internet connection and run the installer again. Finished files are reused.
TimeStamp is not in the Extensions menuQuit and reopen QuPath. Check the User directory in Preferences, then run the installer again and enter that folder.
The microphone test failed or stays silentSetup still finishes. Check the microphone is connected and allowed in your computer’s privacy settings, then use Test microphone in TimeStamp.
The final transcript takes too longChoose Cancel final pass · keep saved audio. The audio is kept; use More → Retry final transcription later.

Getting help

In the recorder, choose More → Copy support information and send it with a short description of the step that failed and the exact message shown. Never send recordings, transcripts or screenshots containing patient information.

This is a preview for supervised evaluation. It is not clinically validated: review every transcript against the recording before relying on it. Recording and transcription run on this computer after setup; audio is not sent to a transcription service. Working recordings stay in the QuPath User directory under timestamp/recordings, even when audio is not included in a saved session. Follow your organization’s storage and retention policy.
