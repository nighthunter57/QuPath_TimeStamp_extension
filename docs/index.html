Core capabilities

Designed for lab demos, annotation walkthroughs, and reproducible review sessions where slide context and timing need to stay aligned.

01

Event timeline

Record clicks, zoom gestures, pan gestures, tool changes, and annotation changes with millisecond timestamps.

02

View-state capture

Store viewport x, y, width, height, z, t, and downsample so each event can be reconstructed in slide context.

03

Annotation geometry

Export ROI type, bounds, point count, and vertices for annotation add and delete events.

04

Live monitor

Use the TimeStamp Monitor tab to start, pause, clear logs, follow events, and inspect transcript status.

05

Transcript sync

Optionally launch faster-whisper transcription with microphone level feedback and editable text output.

06

Export package

Save event logs as JSON or CSV, mouse movement as JSON, and transcript text for downstream review.

Installation pipeline

Build the extension jar, drag it into QuPath, and optionally prepare the local Python environment for live transcription.

1

Install Java 21 and QuPath

Use a Java 21 JDK and a compatible QuPath installation before building the extension.

2

Build the extension jar

From the repository root, run the Gradle wrapper.

./gradlew build
3

Install in QuPath

Drag the generated jar into the active QuPath window.

build/libs/TimeStamp-0.1.0-SNAPSHOT.jar
4

Verify the extension

Confirm the menu and monitor tab appear after installation.

Extensions > TimeStamp Extension
Analysis tab > TimeStamp Monitor

Optional transcript setup

Live transcription is powered by the repository scripts and a local Python virtual environment.

python3 -m venv .venv-whisper
source .venv-whisper/bin/activate
python -m pip install --upgrade pip
python -m pip install faster-whisper sounddevice numpy

Recording workflow

Prepare a session folder, capture slide interactions, export structured logs, then review everything against the video and transcript.

01

Prepare session

Create folders and expected filenames.

./scripts/prepare_demo.sh <demo_name>
02

Select folder

Choose the session folder in the TimeStamp menu.

03

Start recording

Begin capture in the TimeStamp Monitor.

04

Review slide

Zoom, pan, change tools, and annotate regions.

05

Pause

Stop event capture while keeping the logs available.

06

Export

Save event JSON, CSV, mouse JSON, and transcript text.

07

Review files

Compare exported events with video and narration.

Output package

Each session can be saved with consistent filenames for downstream analysis or reproducible demonstration review.

*_event.json

Semantic events

Click, zoom, pan, tool, annotation, and view-bound records.

*_cursor.json

Mouse path

Optional throttled movement trail for higher-fidelity cursor review.

*_video.mp4

Screen recording

Reference video that preserves visual context during the session.

*_transcript.txt

Narration text

Searchable live or edited transcript aligned with the review.
