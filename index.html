Install

Plug the extension into QuPath

This is written for doctors and clinical staff: no command line, no code, and no build step.

01

Download QuPath

Choose the button that matches the computer. If QuPath is already installed, skip this step.

02

Download TimeStamp Extension

The extension is a small .jar file. Keep it somewhere easy to find, like Downloads.

03

Open QuPath

Start QuPath like any other application. No coding or terminal window is needed.

04

Drag the extension into QuPath

Drag the downloaded .jar file onto the QuPath window. QuPath will ask to install it.

05

Restart and confirm

Restart QuPath, then check Extensions > TimeStamp Extension or open the TimeStamp Monitor.

What it does

A simple recorder for slide review behavior

Doctors can review normally while TimeStamp quietly records the moments that matter for the research team.

Records what happened

Clicks, zooms, pans, tool changes, and annotation changes are saved in order.

Tracks annotation moments

When a region is drawn or removed, the extension records the shape and timing.

Shows a live monitor

Doctors can see recording status, recent events, and transcript status while reviewing slides.

Supports live notes

Optional transcript capture makes spoken review comments searchable later.

Pairs with screen video

Use a normal screen recorder while TimeStamp captures the structured event timeline.

Exports review files

Export event logs, cursor movement, video, and transcript files for follow-up analysis.

During a session

Review slides the normal way

The extension is designed to stay out of the way while preserving a record for later review.

Doctor workflow

These are the only actions a reviewer needs to remember.

  1. 1Start screen recording if you want video.
  2. 2Click Start Recording in the TimeStamp Monitor.
  3. 3Review the slide naturally: zoom, pan, discuss, and annotate.
  4. 4Click Pause Recording when finished.
  5. 5Export the event log, mouse log, and transcript for the research team.

What the research team receives

TimeStamp creates review files that can be matched with the screen recording and transcript.

*_event.json

Review events and slide position

*_cursor.json

Optional cursor movement

*_video.mp4

Screen recording

*_transcript.txt

Searchable spoken notes
